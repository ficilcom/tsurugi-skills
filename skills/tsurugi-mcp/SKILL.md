# Tsurugi MCP の接続と使い方

剣-TSURUGI- は、マーケターと企業が実績を公開し、仕事のパートナーを探せるビジネス SNS。MCP サーバーにつなぐと、AI から自分の個人アカウントの実績・受注者プロフィール・案件・応募・案件メッセージを扱える。

- MCP の URL: `https://tsurugi.marketing/mcp`
- 認証: ブラウザで Tsurugi にログインし、同意画面で「許可する」
- クライアント別の接続手順: [references/connect.md](references/connect.md)

## 接続を確かめる

1. Tsurugi のツール（例: `list_own_track_records`）が使えるか確認する。使えなければ connect.md の手順を案内する。
2. 使えるツールはサーバー側の対応状況で変わる。操作の前に、いま使えるツールの一覧に目的のツールがあるか確かめる。無ければ「この操作はまだ MCP から使えません」と伝え、Web の画面を案内する。

## 知っておくこと

- **個人アカウントとして動く。** ブラウザで企業アカウントに切り替えていても、MCP の操作は常に個人アカウント。企業アカウントの実績や案件は扱えない。
- **同意は全部許可か拒否のどちらか。** 一部の権限だけを許可することはできない。
- **MCP からできないことは Web で行う。** 画像・PDF のアップロード、企業アカウントの操作、案件の公開範囲の変更、表示名・プロフィール画像の変更、いいね・コメント・保存。
- **通知は届かない。** 応募やメッセージにメール・プッシュ通知は無いので、メッセージは自分から確認する（`tsurugi-messages`）。

## 共通ルール

- ツールの入力項目は、その場のツール定義に従う。
- 実績・受注者プロフィール・案件の更新は**全項目の置き換え**。省いた項目は消えるので、先に取得して、変えない項目は現在の値をそのまま渡す。
- 一覧は `limit`（最大 50）と `offset` で続きを取る。
- エラーは日本語の文言で返る。そのままユーザーに伝え、直し方を提案する。

## 必ずユーザーに確認してから実行する操作

内容を見せ、ユーザーが明示的に「実行して」と言ってから呼ぶ。

- 相手や一般に見える操作: 実績の公開、受注者プロフィールの保存（保存するとすぐ公開される）、案件への応募、メッセージの送信、案件の公開・募集終了・再公開
- 取り消せない操作: 実績の削除、応募の辞退（同じ案件には再応募できない）、応募の承諾・却下

## エラーと対処

| 症状 | 対処 |
|---|---|
| 401（認証エラー） | ログインし直す（connect.md） |
| 403 `insufficient_scope` | いったんログアウトしてからログインし直す。以前の接続に新しい権限が含まれていない |
| 「この操作は許可されていません」 | 他人や企業アカウントのものを操作しようとしている |
| 「〜が見つかりません」 | ID の誤り、または状態が合っていない（例: 公開中の実績をもう一度公開しようとした） |
| 入力エラー | ツール定義の必須項目と型を見直す |

## 関連スキル

- 実績を書く・直す: `tsurugi-track-record`
- 受注者プロフィールを整える: `tsurugi-provider-profile`
- 案件を探して応募する: `tsurugi-order-application`
- メッセージを確認・返信する: `tsurugi-messages`
- 発注者として案件を出す: `tsurugi-order-posting`
- 届いた応募を比べて承諾する: `tsurugi-applicant-selection`
